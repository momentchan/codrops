# Still article — tone guide

Use this when drafting or editing `wordpress.md`. Cursor picks this up via `.cursor/rules/codrops-article-tone.mdc`.

## Voice

Frank, direct, conversational. Like talking to another dev about what you built — not a pitch, not a paper.

- **OK:** "I found this poster", "the part I keep noticing", "I tried", "more steps and it stops reading like print"
- **Not OK:** "what sold it for me", "I kept coming back to", punchy one-liners for drama

## Story

Write the astronaut story as story. Save "I wanted / I wrote" for why you built a technique, not for plot.

## Prose habits

| Avoid | Prefer |
|-------|--------|
| Academic shader talk | Plain names + code tokens |
| Many short sentences | One flowing paragraph |
| "Demo sphere" in article text | Name the effect |
| "Cartoon" | Anime, Japanese print, ink |
| Performative emotion | Understated personal ("I liked this shadow a lot" → "the part I keep noticing") |

## Structure (Codrops)

- Opening paragraphs before first H2 (no "Intro" heading if short)
- H2 for major sections (Japanese Print Style, The Field, …)
- H4 for techniques
- **Bold** for named techniques
- Short code for your non-obvious bits only
